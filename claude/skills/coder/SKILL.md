# coder

编码时应遵循的规范

## 编码规范

- 变量命名：        变量名应具有描述性，能清楚表明其用途。
- 函数命名：        函数名应使用动词，描述函数的行为。
- 类命名：          类名通常使用驼峰式命名法，并应具有描述性。
- 注释规范：        注释应简洁明了，解释代码的意图或复杂逻辑。
- 避免重复代码:     将重复的代码提取到函数或类中可以提高代码的可维护性。
- 遵循单一职责原则: 每个函数或类应具有单一职责。
- 设计模式：        善于运用设计模式。

**IMPORTANT**: 请按上述规范执行编码
