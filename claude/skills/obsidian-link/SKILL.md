# obsidian-link

obsidian-link 是提供 AI 如何在笔记仓库中，为指定的笔记建立 wiki 链接的指南。AI应参考该指南替用户实现笔记仓库中笔记之间的链接关系。

## 环境验证

**重要**：如果有 Search 工具，则跳过该步骤。

### 1. 操作系统是 MacOS 或 Linux

1. 首先验证环境中是否有 `grep` 命令。
2. 如果没有 `grep` 命令，验证是否存在 `ripgrep` 命令。
3. 如果都没有则进入“环境安装”这一步。


### 2. 操作系统是 Windows

1. 直接验证是否有 `ripgrep` 命令。
2. 如果没有则进入“环境安装”这一步。

**grep 验证命令**

```sh
grep -h
```

**ripgrep 验证命令**

```sh
ripgrep -h
```

## 环境安装

在 MacOS 或 Linux 操作系统上使用下列命令完成安装

```sh
brew install ripgrep
```

## wiki 链接

在Obsidian仓库中你必须按照下列格式来创建wiki链接

[[关键概念]] # 笔记名刚好为关键概念
[[关键概念|别名]] # 笔记名不为关键概念，但是内容与关键概念有关。

## 工作流程

### Pharse 1： 环境准备

按照“环境准备”章节所描述的内容进行验证。若已验证过，则该步骤可跳过，否则**必须执行**。


### Pharse 2:  记录笔记中的关键概念

**重要** ： 代码块，数学公式，标题中的内容不能用作关键概念

笔记中的关键概念指用户必须理解或知晓的单词或句子，用户如果对此处有疑问，则会影响到对整篇笔记的理解或无法按照笔记中约定的步骤去执行/复现。


例1: 在笔记《安装Neovim》中有内容如下：“使用 HomeBrew 安装 Neovim。” 的关键概念就是 HomeBrew。因为如果用户未安装 HomeBrew
且用户不了解如何安装 HomeBrew， 那么用户就无法按笔记中的教程使用 Homebrew 安装 Neovim 了。

然后将笔记中的关键概念整理成一个任务列表，示例如下：

- [ ] 关键概念1
- [ ] 关键概念2
- [ ] 关键概念3
- [ ] 关键概念4
- [ ] 关键概念5

### Pharse 3: 搜索笔记库建立链接

优先使用 Search 命令，如果没有则使用 `grep` 或 `ripgrep` 命令搜索与关键字相联的文章，将关键概念与该文章进行 wiki 链接。
