## 工作流程

### 获取改动内容

了解当前git仓库做了哪些改动。

### 根据内容分类

结合git仓库和改动内容将修改按内容划分出至少一个主题。

### 按分类提交

将划分出来的主题逐个进行提交。

#### 同一文件涉及多主题

如果多个主题的修改内容都涉及到了同一个文件， 使用命令 `git add -p` 交互式暂存此次提交相关的内容。

## 不能做

❌ git log 查看提交日志
❌ 提交中携带 主体(body) 和 页脚（Footr)信息。

如果违反了规则，你将会被收取 100 万美元的罚金。
