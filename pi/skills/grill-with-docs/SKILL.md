1. 用 `read` 读取 [grilling](../grilling/SKILL.md) 和 [domain-modeling](../domain-modeling/SKILL.md)。
2. 按 grilling 的依赖前沿分轮提问；用户确认的术语才进入 CONTEXT.md。
3. 决策确定后读取 [decision-notes](../decision-notes/SKILL.md)，先查归属再决定更新或新建。讨论通过但尚未实现的方案保持 proposed。
4. 用户调用本入口授权记录讨论成果，不等于授权修改生产代码、提交 Git 或发布 Issue。

路径与调用方式见 [pi 宿主适配](../_maintenance/PI-RUNTIME.md)。
