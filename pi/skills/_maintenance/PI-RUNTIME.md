# pi 宿主适配

仅在跨 skill 组合、调用脚本、委派或发布外部产物时读取。本文件只描述 pi 接口；项目与用户约束仍以当前会话中的高优先级指令为准。

## 加载与路径

- 用 `read` 读取所引用的 `SKILL.md`，没有专用的 skill 调用工具。链接相对**包含链接的文件目录**解析；交给工具时转换成绝对路径。
- `disable-model-invocation: true` 让入口不出现在模型自动发现列表；用户仍可通过 `/skill:<name>` 加载。正文中的参考文件链接仍可读取，不是访问权限隔离。
- 默认自动发现入口应写清触发分支。快捷别名仅供用户显式调用，业务规则只放在实际 skill 中。
- 安装资源（脚本、模板、prompts）相对 skill 目录；任务输入输出相对用户工作区。运行全局脚本时保持 cwd 为项目根，或显式传工作区。
- 更新后用 `/reload` 刷新资源；本会话已经读过的正文不会自动从上下文消失，行为验收使用新会话。

## 工具与能力

- 命令通过 Bash；检索使用 `rg` 和 `fd`。Windows＋Bash 不使用 NUL 重定向。
- 修改前读取文件；局部修改用 `edit`，新文件或整体改写用 `write`。
- 先探测所需解释器、库和应用。缺失时报告缺口；安装依赖或创建业务数据前确认目标环境，避免污染用户项目。
- 简单事实直接查。独立而较大的只读探索可委派；先调用 `subagent` 的 `action: list`，仅使用实际可执行的 agent。当前常用 `explorer` 查事实，`reviewer` 做独立审查；不存在时自己执行只读检查。
- 默认子 agent 不会编排子任务。父会话负责组合；同一工作树只有一个写入者，并行改代码时使用宿主管理的隔离工作树。
- 不凭空调用未配置的设置命令或 tracker。外部发布走可用工具，先发现能力并读取其参数；无法发布时留下明确的本地草稿，不报告成已发布。

## 交付

报告实际改动、执行过的验证、未验证事项和产物路径。测试通过不等于语义正确；未运行不能写成通过。凭据、原始敏感请求和无必要的用户正文不进入日志、Note 或测试夹具。
