# Triage labels

使用默认的五个分诊状态；在本地 Markdown 任务文件的 `Status:` 行中记录对应值。

| 技能中的角色 | 本仓库状态值 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给代理实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能要求应用某个分诊角色时，使用本表中的状态值。需要更换词汇时，修改“本仓库状态值”列。
